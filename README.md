# APT Cognitive Organism

APT is a deterministic, local-first research substrate for persistent state,
content-addressed memory, measurable cognition signals, hypothesis comparison,
and byte-level learning from randomly initialized weights.

This repository makes a deliberately narrow claim: it is a working experimental
system, **not AGI, consciousness, or a proven replacement for transformers**.
Every reported quantity maps to inspectable code and every model comparison
reports losses, runtime, parameter counts, initialization, and limitations.

## What is implemented

| Subsystem | Implementation | Persistence / validation |
|---|---|---|
| Precision kernel | `Decimal`, exact fractions, validated bisection and Newton square root | Explicit contracts and convergence failures |
| Timeline | Append-only SQLite DAG | Branch, commit, rewind, checkout, replay; WAL + full sync |
| Memory | SHA-256-addressed episodic and semantic objects | Immutable objects plus repeatable occurrence records |
| Retrieval | Transparent signed byte n-gram vectors | Deterministic cosine search; no downloaded embedding model |
| Metrics | Novelty, coherence, byte entropy and repetition | Defined formulas; no random scores |
| APT byte model | Multi-timescale predictive traces with learned softmax readout | Local training, save/load, deterministic seeded generation |
| Baselines | Fully trainable NumPy Elman RNN and one-layer causal transformer | Same byte corpus and next-byte loss interface |
| Simulation | Evidence/coherence/prior/novelty/complexity/risk scoring | Auditable utility formula and ranked comparison weights |

## Install in one command

Python 3.10 or newer is required.

```bash
python install.py
```

On Windows, `py install.py` works when the Python launcher is installed. The
installer creates `.venv`, installs APT, and runs the complete test suite. It
does not download model weights or contact an AI service.

Initialize a state directory:

```bash
.venv/bin/apt-cognitive --home .apt init
```

Windows:

```powershell
.venv\Scripts\apt-cognitive.exe --home .apt init
```

## Operating examples

Persist and measure an episode:

```bash
apt-cognitive --home .apt observe "The field trial produced a stable 1.4 tesla measurement."
```

Store a semantic assertion and retrieve related memories:

```bash
apt-cognitive --home .apt observe --semantic "Timeline rewinds move heads but never erase history."
apt-cognitive --home .apt recall "persistent timeline history"
```

Fork and replay a real alternate timeline:

```bash
apt-cognitive --home .apt branch experiment
apt-cognitive --home .apt observe --branch experiment "Changed the simulator weights."
apt-cognitive --home .apt rewind --branch experiment --steps 1
apt-cognitive --home .apt replay --branch experiment
```

Train only on a local corpus and generate deterministically:

```bash
apt-cognitive --home .apt train corpus.txt --epochs 3
apt-cognitive --home .apt generate "APT " --bytes 128 --seed 37
```

Score candidate hypotheses:

```bash
apt-cognitive --home .apt consider "Which storage design survives crashes?" \
  --candidate "SQLite WAL with full synchronization" --evidence 0.9 \
  --candidate "Unflushed in-memory dictionaries" --evidence 0.1
```

## Tests

The suite uses Python's standard `unittest` runner:

```bash
python -m unittest discover -s tests -v
```

Tests cover numerical contracts, exact reconstruction, invalid brackets,
timeline divergence and persistence, duplicate memory occurrences, deterministic
metrics, training, model serialization, seeded generation, hypothesis ranking,
integrated operation, and benchmark schema.

## Honest model comparison

```bash
python -m benchmarks.compare_models --epochs 1 --output benchmark-results.json
```

The comparison reports:

- validation next-byte cross-entropy in bits per byte (lower is better);
- loss before and after training;
- parameter count;
- elapsed training time and bytes per second;
- greedy generated bytes in UTF-8 and exact hexadecimal form;
- Python, NumPy, platform, seed, split, optimizer and caveats.

The models are intentionally small and are **not parameter-matched**. Results on
the bundled micro-corpus establish that the harness works; they do not establish
general language superiority. See [docs/BENCHMARKS.md](docs/BENCHMARKS.md).

## Limits that matter

- The byte n-gram memory encoder measures lexical structure, not human-level meaning.
- The APT byte predictor is a compact experimental state model, not a foundation model.
- Training from scratch means useful output requires a relevant local corpus.
- SQLite gives durable local state, not distributed consensus.
- Simulator comparison weights are relative scores, not calibrated probabilities.
- No claim of subjective experience or consciousness is made or tested here.
